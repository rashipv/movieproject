

# Movie Project

This Django-based project allows users to list, create, update, and delete movie records. It includes features like adding movie details and managing them through CRUD (Create, Read, Update, Delete) operations. 

## Installation

To set up the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/rashipv/movieproject.git
   ```
2. Navigate to the project directory:
   ```bash
   cd movieproject
   ```
3. Install the required dependencies:
   ```bash
   pip install django pillow
   ```

## Usage

Run the Django development server:
```bash
python manage.py runserver
```
Access the project at `http://127.0.0.1:8000/`.
